# Kata 1 - Clase Person

Este proyecto contiene la resolución de la Kata 1 para la asignatura de Ingeniería de Software II.

## Estructura del proyecto
* `Person`: Clase de dominio que almacena el nombre y la fecha de nacimiento, calculando tambien la edad de la persona.
* `Main`: Punto de entrada que instancia un objeto y muestra los resultados por consola.

## Tecnologías utilizadas
* Java JDK: 26
* IntelliJ IDEA
* Git Flow
